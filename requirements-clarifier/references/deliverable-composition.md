# Deliverable Composition（交付物构成模板）

用途：把“交付物”拆成可检查的组成件，降低对齐成本。

## Deliverables
为每个交付物写清：
- Name：
- Purpose（作用/用途）：
- Audience（给谁用）：
- Structure（结构/字段/章节）：
- Variables（可替换变量槽位）：
- Format（输出格式）：Markdown / JSON / Doc / PPT / Code / Table / etc.
- Quality bar（质量条款）：一致性/事实性/可追溯/可回滚/合规
- Example（1个最小样例，可选）：

## 常见交付物“拆法”示例
### A) 文档类（方案/PRD/说明）
- 背景
- 目标
- 非目标
- 方案
- 风险与假设
- 验收

### B) 清单类（执行/排期/检查表）
- 条目
- 优先级
- Owner
- 截止时间
- 完成定义

### C) 内容类（文案/脚本/帖子）
- 标题
- 开头钩子
- 主体结构（1-3段）
- CTA
- 标签/元信息
- 禁区与替代表达

### D) 代码/脚本类
- 输入参数
- 输出
- 运行方式
- 错误处理
- 测试/验证
