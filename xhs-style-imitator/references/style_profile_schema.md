# Style Profile Schema（单篇样本风格指纹）

> 目标：用 10-20 行把“这篇笔记怎么写的”描述清楚，便于仿写。

## 1) 基础信息
- 领域/主题：
- 受众：
- 写作目的：种草/科普/盘点/测评/教程/观点

## 2) 标题指纹
- 句式：数字开头 / 对比 / 反问 / 悬念 / 直接结论
- 标点：！数量、是否“？”
- 长度：约 xx 字
- 关键词位置：前置/后置

## 3) 开头钩子
- 首段功能：直接给数据/给结论/抛痛点/讲经历
- 首段长度：短/中/长

## 4) 结构与排版
- 段落长度：短段为主/长段为主
- 空行频率：高/中/低
- 小标题：是否用“：”或“【】”
- 常见组件：分点清单、括号补充、引用、总结句

## 5) 语言与语气
- 人设：专业分析/朋友聊天/吐槽/温柔治愈
- 情绪强度：克制/中性/强烈
- 常用连接词：
- 高频词/短语：
- 是否用表情符号：不用/少量/密集（类型：🔥✅💡等）

## 6) 信息组织方式
- 论证方式：数据→结论 / 结论→解释 / 对比表 / 盘点排名
- 每段信息密度：高/中/低

## 7) 标签风格
- 格式：#xx# / #xx[话题]#
- 数量：约 xx 个
- 标签类型：领域词/人群词/场景词/动作词

## 8) 禁区（防抄袭）
- 样本中独特句式/比喻/口头禅（仿写时避免直接复用）：
